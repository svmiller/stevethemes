# "Brandys", 1942-2017

This is a simple data set on the yearly registration of new "Brandy"s by
the Social Security Administration.

## Usage

``` r
brandy
```

## Format

A data frame with 76 rows and 5 columns

- `year`:

  a year

- `sex`:

  a character of "F" for "female"

- `name`:

  a character, "Brandy"

- `n`:

  the number of new "Brandy"s registered that year

- `prop`:

  the proportion of all registrations of that name for that sex in that
  year

## Details

Data come from the Social Security Administration, by way of the
babynames package. Entries only here for names with at least 5 new
registrations in a year.
