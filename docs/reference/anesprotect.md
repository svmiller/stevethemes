# Support for Trade Protectionism in the U.S., 2012 and 2020

This is a simple data set on the partisan breakdown of support for
limiting foreign imports to protect American workers in both 2012 and
2020.

## Usage

``` r
anesprotect
```

## Format

A data frame with 14 rows and 3 columns

- `year`:

  a year

- `pid7`:

  a factor of partisanship on a 7-point scale from "Strong Democrat" to
  "Strong Republican"

- `prop`:

  the proportion of repsondents in that category that would favor
  limiting imports

## Details

Data come from the American National Election Studies in 2012 and 2020.
Be mindful that, if given the option, most Americans will say they
haven't thought too much about this question.
