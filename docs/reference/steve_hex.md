# Some Hex Triplets I Find Useful/Interesting/Fun

This is a simple data frame with labels corresponding to hex triplets
(i.e. web colors) that I find useful, interesting, or fun.

## Usage

``` r
steve_hex
```

## Format

A data frame the following 2 variables.

- `color`:

  a character vector describing the color in question

- `hex`:

  a hex triplet (with preceding hashtag) of the color

## Details

Data exist to be used by [`g_c()`](http://svmiller.com/reference/g_c.md)
in this same package.
